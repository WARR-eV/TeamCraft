Usage statistics

The desktop apps send this server one anonymous report per day of use: a random installation id, the app version, operating system, package type, active minutes and counts of fixed actions – never names, numbers, paths, search terms or anything typed. They stay on this server. Sharing an aggregate with the TeamCraft developers is off until you turn it on.
